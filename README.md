# بيانات «الأخبار التقنية اليومية»

هذا المستودع يحفظ أعداد نشرة الأخبار التقنية المعروضة في موقع مؤسسة ركن السمو لتقنية المعلومات:
**https://sumoucorner.com.sa/news-tech/**

الصفحة تقرأ ملفات الأخبار مباشرة من هذا المستودع (الفرع `main`)، لذلك يظهر أي عدد جديد في الموقع خلال دقائق من رفعه إلى هنا.

## محتويات المستودع

| المسار | الوظيفة |
| --- | --- |
| `news-tech/data/YYYY-MM-DD.json` | عدد كل يوم (ملف واحد لكل يوم) |
| `news-tech/data/index.json` | فهرس أرشيف آخر شهرين، يُنشأ آلياً |
| `news-tech/README.md` | صيغة ملف العدد وقواعد التحرير |
| `tools/publish.py` | يفحص الأعداد ويعيد بناء الفهرس |

## إضافة عدد أو تعديله

1. أنشئ أو عدّل الملف `news-tech/data/YYYY-MM-DD.json` وفق الصيغة في `news-tech/README.md`.
2. شغّل `python3 tools/publish.py` من جذر المستودع. إن وُجد خطأ يُطبع ولا يتغير الفهرس.
3. ارفع التغييرات إلى الفرع `main`.

الأعداد الأقدم من شهرين تبقى محفوظة هنا لكنها لا تظهر في أرشيف الموقع.
