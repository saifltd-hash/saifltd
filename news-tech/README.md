# صيغة العدد اليومي وقواعد التحرير

## صيغة الملف `data/YYYY-MM-DD.json`

```json
{
  "date": "2026-11-22",
  "note": "سطر اختياري يظهر أعلى قائمة الأخبار",
  "items": [
    {
      "id": "short-latin-slug",
      "category": "ai",
      "lead": true,
      "title": "عنوان الخبر بالعربية",
      "summary": "ملخص من جملتين إلى ثلاث بصياغة أصلية.",
      "source": "اسم المصدر",
      "url": "https://example.com/the-article",
      "published": "2026-11-21"
    }
  ]
}
```

| الحقل | الشرح |
| --- | --- |
| `date` | تاريخ العدد بتوقيت الرياض، ويطابق اسم الملف |
| `note` | اختياري |
| `id` | معرّف فريد داخل العدد: حروف لاتينية صغيرة وأرقام وشرطات، من 3 إلى 80 حرفاً |
| `category` | أحد القيم: `ai` الذكاء الاصطناعي، `security` الأمن السيبراني، `infra` الشبكات والبنية التحتية، `saudi` التقنية في السعودية، `business` أعمال التقنية، `hardware` العتاد والشرائح، `devices` الأجهزة، `science` العلوم والفضاء، `other` منوعات |
| `lead` | `true` لخبر واحد فقط: الخبر الأبرز الذي يتصدر الصفحة |
| `top` | `true` لثلاثة أخبار على الأكثر تظهر في شريط «الأكثر تداولاً عالمياً» |
| `title` | من 10 إلى 170 حرفاً |
| `summary` | من 60 إلى 750 حرفاً |
| `source` | اسم الجهة الناشرة كما تُعرف |
| `url` | رابط الخبر نفسه في مصدره (http أو https) |
| `published` | تاريخ نشر الخبر في مصدره، ولا يتجاوز تاريخ العدد |

عدد الأخبار في العدد الواحد من 5 إلى 40، والمعتاد من 12 إلى 16.

## قواعد التحرير

- **الاختيار:** الأهم والأكثر تداولاً عالمياً، أي الأخبار التي غطّتها عدة مصادر كبرى في اليوم نفسه. الخبر الأبرز `lead` هو الأوسع تغطية، وأخبار `top` هي الثلاثة التي تليه.
- **الحداثة:** أخبار آخر 24 إلى 48 ساعة. لا يُكرَّر خبر ورد في عدد سابق إلا إذا جدّ فيه تطور.
- **التوازن:** تغطية أغلب المجالات كل يوم، مع خبر سعودي أو خليجي واحد على الأقل متى وُجد.
- **الصياغة:** ملخص عربي أصلي من جملتين إلى ثلاث، بلا نقل حرفي ولا ترجمة كاملة للمقال. الأرقام والتواريخ والأسماء تُنقل بدقة من المصدر.
- **المصدر:** لكل خبر رابط مباشر إلى مصدر موثوق، ويُفضَّل المصدر الأصلي (بيان الشركة أو الجهة الرسمية) أو وسيلة إعلام معروفة.
- **الدقة:** لا يُنشر رقم أو ادعاء لم يرد في المصدر. الأخبار غير المؤكدة تُنسب إلى من نقلها («بحسب تقرير لـ…»).
- **الحياد:** لغة خبرية بلا رأي ولا ترويج، خصوصاً في الأخبار ذات الطابع السياسي.
